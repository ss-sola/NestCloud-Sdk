# 进程指标接口

使用 SDK `bootstrap()` 的服务可在本地 `.env` 或进程环境设置 `ServiceMonitorToken`，启用 `GET /_internal/process-metrics`。路径与 `GlobalPrefix` 无关。每个部署使用独立、至少 32 字符的随机密钥。

注册中心用 `ProcessMetricsAuth.sign(token, url.host)` 生成 `X-Service-Monitor-Signature`。签名绑定目标地址和路径，有效时钟偏差为 30 秒。无效签名返回 401。部署时仅允许可信网络访问。

返回 JSON 字段为 `collectedAt`、`cpuPercent`、`cpuWindowMs`、`rssBytes`、`heapUsedBytes`、`heapTotalBytes` 和 `uptimeSeconds`。CPU 每 2 秒采样，以一个逻辑 CPU 满载为 100%，多线程进程可超过 100%。首次采样前 CPU 值及窗口为 `null`。

`cpuLogicalCoreCount` 和 `systemTotalMemoryBytes` 是实例运行环境报告的逻辑核心数和系统总内存（字节）。旧 SDK 的响应可缺省这两个字段。

`systemUsedMemoryBytes` 为系统总内存减去空闲内存。`diskTotalBytes` 和 `diskUsedBytes` 对应服务工作目录所在文件系统的总容量和已用容量，单位为字节。磁盘每 10 秒独立采样，暂时无法采集时缺省磁盘字段。
